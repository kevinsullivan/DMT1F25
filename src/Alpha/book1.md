# Book 1: Constructive Propositional Logic
## Proofs as Programs in Lean

This book introduces constructive propositional logic through
the Curry-Howard correspondence. Students learn to construct
proofs as programs in Lean 4, building intuition for each
logical connective through its introduction and elimination rules.

### Topics Covered
- Propositional connectives: True, And, Or, Implies, Iff, False, Not
- Curry-Howard correspondence: Types ↔ Propositions, Programs ↔ Proofs
- Constructive reasoning (no excluded middle assumed)
- Proof construction via lambda abstraction and pattern matching
